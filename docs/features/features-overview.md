# Features Overview

## Core Features

Shop1 CMMS provides comprehensive maintenance management capabilities organized into several key functional areas.

### Asset Management

#### Asset Tracking
- **Asset Registry**: Complete inventory of all equipment and assets
- **Asset Hierarchy**: Parent-child relationships for complex equipment
- **Asset Details**: Comprehensive information including specifications, location, and status
- **Asset History**: Complete audit trail of changes and maintenance activities

#### Asset Operations
- **New Asset Registration**: Quick asset creation with guided forms
- **Bulk Import**: CSV/Excel import for mass asset creation
- **Export Functions**: CSV, Excel, and PDF export capabilities
- **Asset Search**: Advanced search and filtering across all asset attributes

#### Asset Status Management
- **Status Tracking**: Active, Inactive, Under Maintenance, Retired
- **Criticality Levels**: Critical, High, Medium, Low priority classification
- **Location Management**: Site-specific asset organization
- **Asset Types**: Categorization by equipment type

### Work Order Management

#### Work Order Lifecycle
- **Creation**: Manual creation and automated generation from PMs
- **Assignment**: Technician assignment with skill-based routing
- **Progress Tracking**: Real-time status updates and time tracking
- **Completion**: Digital sign-off with required documentation

#### Work Order Features
- **Priority Management**: Emergency, High, Medium, Low priorities
- **Scheduling**: Planned vs. unplanned work coordination
- **Parts Management**: Parts requests and inventory integration
- **Labor Tracking**: Time and cost tracking per work order

#### Reporting and Analytics
- **Work Order Reports**: Status, completion rates, and efficiency metrics
- **Downtime Analysis**: Equipment availability and reliability tracking
- **Cost Analysis**: Labor, parts, and total maintenance costs
- **Performance Metrics**: KPIs and dashboard visualizations

### Preventive Maintenance

#### PM Program Management
- **PM Templates**: Standardized maintenance procedures
- **Scheduling**: Calendar-based and meter-based scheduling
- **Auto-Generation**: Automatic work order creation from PM schedules
- **Compliance Tracking**: Regulatory and manufacturer requirement compliance

#### PM Features
- **Multi-Schedule Support**: Multiple PM schedules per asset
- **Flexible Intervals**: Time-based, usage-based, and condition-based
- **Task Management**: Detailed checklist and procedure management
- **Resource Planning**: Parts and labor requirement planning

### Inventory Management

#### Parts and Supplies
- **Parts Catalog**: Comprehensive parts database with specifications
- **Stock Management**: Inventory levels, reorder points, and purchasing
- **Parts Requests**: Work order-driven parts requisition
- **Vendor Management**: Supplier information and purchasing history

#### Inventory Features
- **Stock Tracking**: Real-time inventory levels and locations
- **Cost Management**: Purchase costs and usage tracking
- **Obsolete Parts**: Identification and management of obsolete inventory
- **Reporting**: Inventory valuation and usage reports

### User Management and Security

#### Multi-Tenant Architecture
- **Tenant Isolation**: Complete data separation between organizations
- **Site Management**: Multiple sites per tenant organization
- **Role-Based Access**: Five distinct user roles with appropriate permissions
- **Session Management**: Secure authentication and session handling

#### User Roles and Permissions
- **System Admin**: Complete system administration capabilities
- **Tenant Admin**: Full tenant management and configuration
- **Maintenance Manager**: Work order oversight and PM management
- **Technician**: Work execution and status updates
- **Viewer**: Read-only access to reports and dashboards

### Reporting and Analytics

#### Standard Reports
- **Asset Reports**: Asset inventory, status, and utilization reports
- **Work Order Reports**: Completion rates, backlog, and performance metrics
- **PM Compliance**: Scheduled vs. completed preventive maintenance
- **Cost Reports**: Maintenance costs by asset, department, or time period

#### Dashboard and Metrics
- **Executive Dashboard**: High-level KPIs and performance indicators
- **Operational Dashboard**: Real-time work order and asset status
- **Custom Reports**: Configurable reports based on specific requirements
- **Export Capabilities**: PDF, Excel, and CSV export for all reports

### Integration Capabilities

#### Shop1FinishLine ERP Integration
- **User Authentication**: Shared user system and single sign-on
- **Asset Synchronization**: Bidirectional asset data synchronization
- **Cost Center Integration**: Financial data alignment with ERP
- **Reporting Integration**: Unified reporting across systems

#### External Integrations
- **Equipment APIs**: Integration with equipment manufacturer systems
- **IoT Sensors**: Real-time equipment monitoring and alerts
- **Mobile Applications**: Field technician mobile access
- **Third-Party Tools**: Integration with specialized maintenance tools
